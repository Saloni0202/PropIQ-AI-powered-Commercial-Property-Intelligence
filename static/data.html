Architecture

    

      
1 · Ingest
Seeded generator writes raw CSVs. Pandas standardises text; SQL window functions de-duplicate; CASE-based checks quantify quality; a validation filter creates the analysis table.

      
2 · Model & retrieve
scikit-learn pipelines (impute → scale → encode → regress) with CV and a held-out test. TF-IDF retrieval over section chunks, optional LLM synthesis grounded in sources.

      
3 · Serve
FastAPI exposes /api endpoints and serves this multi-page dashboard. Chart.js and d3 are vendored, so the app runs offline with no external CDN.
