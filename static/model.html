How it was built

    Limitations

    • Synthetic data. Rents were generated from a known formula plus noise, so a good score proves the pipeline works — not that it would work on real CBRE data. Real data has hidden drivers (lease terms, sub-market, tenant credit) this model never sees.
    • Cross-sectional only. The model estimates today's rent for similar assets. It does not forecast future rents; market trends are descriptive.
    • No spatial or time split. Test properties come from the same markets as training ones. Performance on a brand-new market would be worse.
    • Intervals are marginal. The 90% band uses one average relative error, so it is too narrow for volatile segments and too wide for stable ones.
    • Linear form. The winner is a log-linear model; gradient boosting did not beat it here because the data are mostly additive in log space. On messier real data that ordering may flip.
